# LinkedIn / GitHub project announcement draft

I am currently building an educational **Procure-to-Pay (P2P) Process Analysis and Testing** project to strengthen my understanding of enterprise procurement workflows and SAP-related concepts.

The project simulates key procurement stages:
- Purchase order creation
- Goods receipt recording
- Supplier invoice verification
- Simplified three-way matching
- Procurement reporting and SQL analysis

**Technology stack:** Python, Streamlit, SQLite, SQL and Pandas.

Alongside the application, I am preparing business-process documentation and functional test scenarios covering partial deliveries, invoice mismatches, and data validation.

This is a self-directed learning simulation—not a live SAP implementation. My next learning goal is to map the workflow to SAP S/4HANA procurement concepts and study SAP HANA SQL.
